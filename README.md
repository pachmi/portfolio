## How to Run This Project Locally

To run this website from scratch on your own computer:

1. Clone the repository  

2. Navigate to the project folder  

3. Open the site by launching `index.html` in your browser  
You can also use a live server like the VS Code Live Server extension for local development.

---

## Deployment Instructions

This site is deployed using GitHub Pages:

1. Go to the repository settings
2. Click on the "Pages" section in the sidebar
3. Under "Source", select the `main` branch and `/ (root)` folder
4. Save the settings
